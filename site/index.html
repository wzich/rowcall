A quick investigation rarely stays simple.

You bring in another source, join datasets, try a different transformation, and build a model. Rowcall keeps those steps connected in a graph, so you can see how a result was produced and build on the work.

In a notebook, the order you run cells can differ from the order you read them. In Rowcall, connections make dependencies visible and determine which steps run.

Features

Traceable, reproducible analysis

See which steps produce each result. Rowcall runs the required steps in dependency order, so execution follows the graph.

Your machine.
Your environment.

Work locally, with a dedicated Python environment for each project. Your analysis stays in a folder you control.

Your tools,
your agents.

Your analysis lives in ordinary Python files. Use your preferred editor or coding agent alongside Rowcall.

Drag data
onto the canvas.

Drop in CSV, TSV, or Parquet files to create Python steps that load your data. Connect them and start exploring.

How it works

  1. 01

    Start a project

    Run rowcall. The wizard guides you through naming your project, choosing a folder, and selecting Python packages.

  2. 02

    Build your analysis

    Add Python steps, connect their inputs, and inspect the results as you work.

  3. 03

    Edit and rerun

    Edit the Python files in your project folder, reopen the graph, and run it again. Share the files and requirements when you’re ready.

1. Install from your terminal
curl -fsSL https://rowcall.io/install.sh | sh

Follow any PATH instruction printed by the installer.

2. Open the setup wizard
rowcall

Apple Silicon and Intel supported. The binary is unsigned and not notarized. Rowcall runs Python with your permissions; only open code you trust. Unsaved browser edits are lost when the app or browser closes.
