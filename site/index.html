Rowcall Alpha
For agents

A workspace for exploring and building with data

Explore freely.
Keep the work.

Rowcall turns an analysis into an inspectable, runnable graph in an ordinary Python file—so when the work matters later, you can keep going instead of starting over.

Install Rowcall

curl -fsSL \
  https://rowcall.io/install.sh | sh

Invited alpha for macOS. Requires Python 3.10 or newer.

Why Rowcall

01

See how the work fits together

Explore each step, its code, and the data flowing through it in a visual workspace.

02

Move without a rewrite

Your exploration is already a runnable Python graph. Reopen it, extend it, or run it again from the command line.

03

Work directly or delegate

You and your coding agent work on the same ordinary files, while Rowcall keeps the computation easy to inspect.

Start with a project

Create a starter analysis and open it in the Rowcall workspace.

1rowcall new my-work --open
2rowcall validate my-work
3rowcall run my-work --json

Rowcall is an early alpha. It supports the beginning of the path from exploration to production; it is not yet a complete orchestration or hosting system.

The macOS binary is unsigned and unnotarized. Rowcall executes Python with your user permissions, so open only code you trust.
